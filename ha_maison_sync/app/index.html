Première configuration

  1. Copie cette clé publique :
  2. GitHub → dépôt HA-maison → Settings → Deploy keys → Add deploy key → colle la clé et coche Allow write access.
  3. Reviens ici et clique sur « Actualiser ».

Actions

« Envoyer » met à jour GitHub avec ta config actuelle (sans secrets) pour que Claude puisse la lire. « Appliquer » copie les fichiers validés du dépôt dans HA, après sauvegarde, contrôle de la configuration et rechargement. « Brancher » ajoute (une seule fois) les quelques lignes de configuration.yaml qui activent le thème, les helpers et les dashboards.

Nettoyage

Cherche les anciens réglages d'affichage (input_boolean.maison_…) qui ne sont plus définis dans la configuration, et les ressources de dashboards (cartes HACS) qu'aucun de tes dashboards n'utilise. Rien n'est supprimé sans ta confirmation.
